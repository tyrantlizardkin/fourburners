# Brand

The Four Burners logo: a woodcut-style view of a stove top. Four toothed flame rings, each crossed by dark grate bars that line up across the stove, with gouge marks in the open ground.

| File | Use |
|---|---|
| `four-burners-lockup-app.svg` | Mark and name on the app's dark ground. The primary version. |
| `four-burners-lockup-app-transparent.svg` | The same with no background rectangle, for placing on the app's Background color (Empty screen). |
| `four-burners-mark-app.svg` | Mark alone on the dark ground (splash screen). |
| `four-burners-icon.svg` | Simplified mark for small sizes (launcher icon foreground). |
| `four-burners-icon-mono.svg` | Black-on-paper simplified mark; source for the monochrome themed-icon layer. |
| `four-burners-lockup.svg` | Black-on-paper lockup, for use outside the app. |
| `four-burners-mark.svg`, `four-burners-mark-transparent.svg` | Black-on-paper mark, with and without background. |
| `preview-*.png` | Raster previews of the above at 2x. Reference only; build from the SVGs. |

Colors in the app versions: block `#283136` on ground `#1E2529`, letters `#E9EDEA`, gouge marks `#3A474F`, burners `#F0A08C`, `#A3B8F0`, `#A6D4A0`, `#D0A6E6` (the four recipe accents, in order).

Rules are in section 11.5 of the spec. In short: convert the SVGs, do not redraw them; do not recolor or animate; the lettering is drawn shapes, not a font.
