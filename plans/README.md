# Four Burners

Hand-off package for building the Android app.

| Path | What it is |
|---|---|
| `four-burners-android-spec.md` | The spec. Start here; section 3 gives the build order. |
| `sample-plan.json` | The reference plan from section 5.5 of the spec, as a file. Built-in sample and main test fixture. |
| `sender-instructions.txt` | The instructions from section 16, to paste into a Claude chat so it emits plans in the right format. |
| `brand/` | The logo as SVG, in app colors and black-on-paper, plus a simplified icon. See `brand/README.md`. |
| `mockups/` | The visual guide: screen mockups as PNG and HTML. See `mockups/README.md` for which ones match the spec and where they differ. |

The spec is the source of truth. The mockups show the intended look (dark teal-slate ground, pastel accents, IBM Plex Sans headings) and are behind the spec in several details listed in `mockups/README.md`.

The app is named Four Burners. The plan format is still called `cookplan` (JSON key and URL scheme); that is intentional.
